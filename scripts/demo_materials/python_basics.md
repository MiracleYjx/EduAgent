# Python 基础演示教材

本资料为 EduAgent 本地演示编写的合成教材，不含学生信息。

## 变量

变量用于绑定数据，赋值运算符是等号。例如 `count = 3` 将名称 count 绑定到整数 3。
Python 的变量无需提前声明类型；名称可在后续赋值时指向其他值。

## 函数

函数用于封装可重复调用的逻辑，减少重复代码。Python 使用 def 关键字定义函数。
参数把调用者的数据传入函数，return 语句把计算结果返回调用者。
例如 `def add(a, b): return a + b` 接收两个参数并返回它们的和。

## 条件分支

if、elif 和 else 根据条件决定执行哪个分支。缩进界定代码块。
比较条件的结果是真或假；多个条件可以通过 and、or、not 组合。
