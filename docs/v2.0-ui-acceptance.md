## 修复与验证

- 知识库、考试和阅卷将只读详情与显式编辑分开；取消从授权业务读取原值，不写数据库或审核记录。课程/知识库按钮按窄栏换行；折叠箭头固定12px，实际测量无横向溢出。
- Gradio 表格 SelectData 注入会改变函数位置参数；鉴权包装复用 Gradio special_args 解析实际 State 位置，保留原事件与授权合同。
- 候选批准/退回后回读当前详情及审核旁栏，修复预览已通过而旁栏仍待审的问题，不以旧状态覆盖写入回执。
- 新增4项必要回归，TCR §41；聚焦129 passed/0 skipped，11项既有警告。后续修复验证27 passed；最终源码 mypy 后端213文件、Ruff及 Black 均通过。既有测试未修改。

## 实际限制与后续验收

学生首页的汇总成绩投影仍未提供，现明确提示进入可用的“成绩与诊断”；未虚构汇总值。展开编辑后的取消已验证字段还原，不承诺自动折叠。教师分析/学生诊断是只读查看，适用刷新与选择，无新增保存操作。本批不证明云模型准确率、EXE 启动/资源预算或完整闭环；T168 原未达标结论、T146 AI辅助＋开发者审查口径保持，T189–T191继续承接相应验收。
