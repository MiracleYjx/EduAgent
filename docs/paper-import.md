# 试卷导入、校正与入库

文字/扫描/混合PDF或图片导入后先看真实任务状态。文字页使用原生提取，扫描页按显式开启的 RapidOCR＋PP-OCRv5 CPU 权重处理；OCR关闭、模型/解析失败均显示真实原因，不用空题结果表示成功。原卷属于 paper_source，不能进入知识库检索。

1. 上传到所选课程，等待 PendingReview；Failed 保留错误与材料，修正前置后显式重新导入。
2. 在原页与结构化题对照界面进入编辑，核对题序、原题号、题型、题干、选项、答案、Rubric、解析、知识点和真实来源页。取消只恢复当前持久值，保存才写入。
3. options 使用 JSON 保留生产者键顺序；历史 JSONB 丢失顺序标记不伪造。来源页必须真实非空，边界未知可保持null，已给像素框须合法；缺答案/解析保持null。
4. 必要图从真实页裁切并关联。教师核对原图和实际理解条件，解决当前轮次问题；修改图/文字后旧核对失效。只把已核实且不含答案的题图打开 student_visible，默认关闭；原卷、SourcePage及含答案整页永久不对学生开放。**在发布考试前完成开放**，发布后引用保护拒绝改图/可见性。
5. 确认入库是幂等操作，重复确认保留同一正式题与资产身份。拒绝保持真实处置；缺参考答案的题可入库待补全，不能审核入卷。
6. 人工/导入题先显式补全，再选择同课程真实教学Chunk，送审、运行当前语义核验。对模型候选的校正保留原输出/真实来源，不称自动提取准确率。内容修改或改回原文都需要新修订的核验通过和真实审核。

T191 已实际导入、校正并幂等入库3题，保留 C/A/B/D JSON 顺序及缺答案阻断；475×350表格裁图在实际核对后于发布前开放。真实文字生成与原题改编均保留失败输出和AI显式补全，未修改T168质量基准。
