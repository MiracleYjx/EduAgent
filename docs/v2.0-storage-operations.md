# v2.0 文件维护操作（T150–T151）

本工具实现离线维护，不切换配置、不启动/停止现有服务、不清理真实旧副本。当前实际资源映射为 Document、ExportFile；原卷/原页/题图表创建后必须由 E2 接入真实映射，未接入时拒绝完整迁移/备份，不能只复制目录后宣称业务验收。

## 前提与身份

使用项目既有 Python 依赖与 PostgreSQL；先按既有数据库升级流程达到文件元数据/ExportFile 能力（0013），工具不会替用户升级开发库。管理员须在当前数据库真实存在、启用且当前角色仍为 Admin。用现有登录得到的 JWT 放在 EDUAGENT_MAINTENANCE_TOKEN（或 --token-env 指定的环境变量）中，不将令牌放入参数、提交、日志或清单。工具不会改变管理员/教师/学生的课程文件 GET 权限。

pg_dump、pg_restore 使用现有标准 PostgreSQL 客户端：默认 PATH；可用 --pg-client-dir 指定已安装客户端目录，或 --pg-container 显式指定已有数据库容器。容器模式以 pg_control_system 的真实实例标识核对配置中的实例，需要相应 PostgreSQL 运维权限；不猜容器/端口、不自动安装客户端。数据库凭据沿用外置配置，仅在子进程环境传递；备份文件本身含业务数据，按私有运维材料管理。

## 历史迁移

```powershell
python scripts/migrate_storage_paths.py --report D:\EduAgent-maintenance\migration-report.json
```

报告目标必须不存在。实际旧绝对定位、旧相对定位按原方式读取；外地主机路径/NULL 保持未知，不按文件名找替代。复制到 uploads 或 exports 的独立相对定位，核对原稿/副本长度和 SHA-256，取得与文件服务相同的物理路径事务锁，重新读取全部共享引用后同事务更新路径和迁移状态。每个业务身份独立收据，保留 UTC、实际管理员及错误；来源快照、Ready 历史和考试评分不变。

重复执行实读已迁移/原生字节后跳过，不以“目标存在”冒充迁移成功。提交前失败保留旧定位/原稿；提交已成功但收据确认失败会明确已提交事实及真实错误，不回写假失败路径。缺失、未知、失败使退出码为 1，全部已迁移/原生/成功为 0。始终保留旧副本，清理另行授权和核对全部引用。

## 一致备份

先停止全部后端、worker 和业务写入脚本，并确认在途导入/出题/阅卷/上传/导出/迁移结束。工具不替代操作人员停止外部进程；无法确认停写时不能使用确认参数。例：
```powershell
python scripts/backup_restore.py --pg-container eduagent-postgres-1 backup --backup-root D:\EduAgent-backups --writers-stopped --timeout 10
```

备份根须与业务根相互独立。工具创建 creating manifest，取得独占维护标记，有限等待其他客户端连接消失，对全部用户业务表持有 SHARE 锁以阻止写入，并持续检查没有其他连接。文件服务在写原稿、共享关联、导出、收据、清理边界拒绝维护写入；SQL 提交后的收据确认也取得物理事务锁和数据库连接，不能从排空检查遗漏。

同一窗口生成标准 custom dump，复制 uploads/papers/assets/exports 的实际字节和收据，实际文件引用/归属、共享路径全部核对。共享路径仅一份字节，每个 file_id 独立清单。数据库内其他未映射业务 schema、历史外部定位、缺失/未知、未完成收据、无法归属材料等使结果 incomplete；技术错误为 failed。保留 partial dump/复制材料及逐项错误，不用当前数据库/相似文件补清单。只有完整核对和最终清单可靠保存后才输出 complete；最终清单不被后续释放窗口错误改写。

结果为独立 backup_set_UUID/manifest.json、database.dump、files/。complete 退出 0，incomplete/failed 退出 1。维护标记释放异常时保留真实情况，不自行移除他人的标记；操作人员保持写进程停止并核对。正常窗口结束后工具只释放自己标记和表锁，原业务进程仍由操作人员控制。

## 隔离恢复与人工切换

```powershell
python scripts/backup_restore.py --pg-container eduagent-postgres-1 restore --backup-set D:\EduAgent-backups\backup_set_UUID --target-database eduagent_restore_new --target-root D:\EduAgent-restored-new --report D:\EduAgent-maintenance\restore-report.json
```

报告文件、新数据库、新根均不能覆盖已有目标，报告不能写入原业务根。仅接受 complete 集作为完整恢复；其他集保留隔离调查材料，不宣布 verified。先核对同集 Schema/路径/文件集合/长度/摘要，创建新的隔离数据库和根，再以标准 pg_restore 恢复，实际核对 FK、file_id、归属/共享关系和收据；数据库保存的题目/来源/考试/答卷/评分/复核等原事实整体保留，不自动重算，不用 Redis 缓存补成功。

恢复失败或报告写入失败保留新数据库/目录和停写标记；原数据库、根、.env、manifest 均不修改。verified 仅表示本次数据/关系核对通过，隔离根的 .maintenance.json 仍在，未将该数据库接入应用或工作进程；不会自动启用业务写入。隔离环境只能用于检查，不能提前连接业务写进程。

实际切换是另获授权后的人工操作：保持所有业务写进程停止，保存原配置并将数据库/根指向核对通过的隔离环境；按既有启动流程验证实际加载和教师/学生授权读取，再按恢复报告与标记 operation_id 核对移除目标标记、开放写入。启动/读取失败保留两套材料和停写状态；新环境已有真实写入后不得自动回退旧数据。此批仅测试新建隔离库/根，没有执行真实切换或旧材料清理。
